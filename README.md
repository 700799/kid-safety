# Kid Internet Safety Guide

A single-page parent's guide to locking down and monitoring children's internet access.

**Live site:** https://700799.github.io/kid-safety/

## What's inside

- Ten concrete security measures: Firewalla, /etc/hosts blocking, DNS filtering (OpenDNS/CleanBrowsing/NextDNS), Net Nanny, router parental controls, Apple Screen Time / Google Family Link, family VPN (Circle/Bark), SafeSearch enforcement, browser extensions, and social media monitoring (Bark/Qustodio)
- For each measure: why it matters, step-by-step setup, a copyable example configuration, and how children commonly bypass it
- Ten peer-reviewed research citations on why monitoring matters
- Prioritized quick-start checklist for parents

## Deployment

GitHub Pages serves `index.html` from the root of the `main` branch. Enable it under **Settings → Pages → Branch: main / folder: / (root)**.
